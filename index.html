Opsi A · paling cepat

MVP gratis total

  • Basemap: Leaflet + tile OpenStreetMap / CARTO
  • Track: gambar polyline sendiri (haversine) — seperti demo ini
  • Rute: OSRM demo server (hanya untuk uji coba)
  • Cari tempat: Nominatim
Biaya: Rp 0 — cukup untuk mendemokan aplikasi ke pengguna pertama
Opsi B · produksi hemat

Siap naik skala

  • Basemap: MapLibre GL JS + OpenFreeMap (atau MapTiler free ±100rb tile/bln)
  • Rute: OpenRouteService free (2.000 rute/hari) atau GraphHopper
  • Elevasi: OpenTopoData · cuaca: Open-Meteo
  • Geocoding: Nominatim/Photon yang di-self-host
Biaya awal Rp 0, bertambah hanya saat pengguna bertambah
Opsi C · serius

Fitur tingkat Strava

  • Valhalla/ORS di VPS sendiri → rute & isochrone tanpa batas
  • PMTiles untuk peta offline (hemat kuota, jalan tanpa internet)
  • Segmen/heatmap dihitung sendiri dari data pengguna (PostgreSQL + PostGIS)
  • Mapillary untuk foto jalan, Stadia/Mapbox untuk visual
Biaya: satu VPS kecil + data OSM, bukan tagihan per request

Yang penting diperhatikanbukan cuma soal gratis

  • Atribusi wajib. Data OpenStreetMap harus menampilkan © OpenStreetMap contributors. Tanpa ini, aplikasinya melanggar lisensi.
  • "Gratis" bukan "tanpa batas". Server tile komunitas punya kapasitas terbatas — kalau aplikasinya mulai ramai, pindah ke provider berbayar murah atau self-host.
  • Jangan simpan API key di kode frontend. Semua request berbayar/berkuota sebaiknya lewat backend sendiri.
  • Rute berbeda dengan track. Track = titik GPS yang direkam alat (seperti demo ini). Rute = jalan yang dihitung mesin routing (OSRM/ORS/GraphHopper).
  • Data pengguna sensitif. Lokasi + waktu = pola hidup orang. Simpan seperlunya, jangan dijual, jangan dikirim ke pihak ketiga kalau tak perlu.
